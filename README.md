# 🚀 Nova Calculator

A futuristic premium scientific calculator built using **HTML, CSS, and Vanilla JavaScript** with a modern glassmorphism-inspired UI, smooth animations, multiple themes, keyboard support, and advanced scientific operations.

---

# ✨ Features

## 🧮 Basic Operations

* Addition
* Subtraction
* Multiplication
* Division
* Percentage
* Decimal calculations

---

## 🔬 Scientific Functions

* Square Root
* Power Functions
* Trigonometry
* Logarithms
* Exponents
* Factorial
* Pi Support
* Parentheses Expressions

---

## 🎨 Premium UI Features

* Glassmorphism Design
* Smooth Animations
* Neon Glow Effects
* Responsive Layout
* Modern Typography
* Theme Switching
* Animated Buttons
* Elegant Transitions

---

## ⚡ Advanced Features

* Keyboard Support
* Calculation History
* Copy Result
* Error Handling
* Real-Time Expression Display
* Local Storage Support
* Multiple Themes
